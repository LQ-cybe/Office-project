============================================================
  多维表分析插件 — 普通用户快速使用帮助
============================================================

【一、安装说明】

1. 环境要求
   · Microsoft Excel 2010 或更高版本，或 WPS Office 表格（ET）。
   · Windows 7 / 10 / 11（64 位或 32 位均可，请与 Office 位数保持一致）。
   · .NET 8 桌面运行时（Windows Desktop Runtime 8.x）。若安装后插件无法加载，
     请从微软官网下载并安装 ".NET 8 Desktop Runtime"。

2. 安装步骤
   ① 关闭所有正在运行的 Excel / WPS 表格窗口。
   ② 将插件文件夹（包含 MultiTableAddin-AddIn.xll / MultiTableAddin-AddIn64.xll、
      MultiTableAddin.dll 等文件）复制到您希望安装的目录，例如：
        C:\Program Files\多维表分析\
   ③ 根据您的 Office 位数，双击运行对应的安装脚本：
        · 64 位 Office → 运行 "安装-64位.bat"
        · 32 位 Office → 运行 "安装-32位.bat"
   ④ 安装完成后，重新打开 Excel / WPS，在功能区会出现“多维表分析”选项卡。

3. 如何查看 Office 位数
   · Excel：文件 → 账户 → 关于 Excel，查看标题栏是否包含“64 位”。
   · WPS：选项 → 关于 WPS，查看版本信息。

4. 卸载
   运行插件目录下的 "卸载.bat"，或在 Excel/WPS 的“选项 → 加载项 → 转到”中
   取消勾选“多维表分析”后删除插件文件夹即可。


【二、首次使用】

1. 打开插件
   启动 Excel / WPS 后，点击功能区“多维表分析”→“打开多维表”。

2. 准备数据
   插件基于工作簿中的“超级表（ListObject）”工作。如果您的数据区域还不是超级表：
   ① 选中数据区域（包含标题行）。
   ② Excel：插入 → 表格（或按 Ctrl+T）。
      WPS：插入 → 表格 → 确定。
   ③ 确认标题行已转换为表格标题。

3. 打开数据源
   ① 点击插件“打开多维表”按钮，插件会自动扫描当前工作簿中的所有超级表。
   ② 在弹出的数据源选择窗口中，选择要分析的工作表和超级表名称，点击“打开”。
   ③ 首次打开时会自动生成表格、表单、看板、画册、日历、甘特、仪表盘、图表
      共八种默认视图。

4. 界面布局
   · 左侧：视图切换栏，点击可在不同视图间切换。
   · 顶部：当前视图的工具栏，常见按钮包括“新增记录、字段开关、字段设置、
     查找、刷新、设置”。
   · 中间：数据展示区域。
   · 右侧/底部：部分视图会显示记录详情或字段设置面板。


【三、各视图简介】

1. 表格视图
   · 像 Excel 一样逐行展示全部记录。
   · 右键列标题可打开字段设置。
   · 使用“字段开关”控制显示哪些列。
   · 支持按字段分组，并可在数据末尾显示汇总行。

2. 表单视图
   · 一次只显示一条记录，适合逐条录入和核对。
   · 日期时间字段会拆成“日期选择器 + 时间输入框”。
   · 修改后必须点击“保存修改”才会写入 Excel。

3. 看板视图
   · 按分组字段把记录排成多列卡片，可拖拽卡片改变分组。
   · 在“字段开关”中可控制卡片显示哪些字段。
   · 分组字段支持单选、季度、文本等类型。

4. 画册视图
   · 以卡片网格展示记录，突出标题与图片。
   · 图片字段需为本地图片文件路径（Image 类型）。
   · 点击卡片可打开记录详情进行查看或编辑。

5. 日历视图（重点：开始/结束日期与时间）
   · 说明：按日期把记录渲染到日历，支持“日 / 周 / 月”三种视图。
   · 关键字段：
     - 开始日期字段：必须是 Date（日期）或 DateTime（日期时间）类型。
       DateTime 类型可精确到小时和分钟。
     - 结束日期字段（可选）：同样为 Date 或 DateTime 类型。
       设置后任务会按跨天范围显示。
     - 标题字段：显示在日历格子中的任务名称。
     - 颜色字段（可选）：按该字段值自动给任务分色。
   · 重点设定：
     - 在“字段设置 / 日历设置”中指定“开始日期字段、结束日期字段、标题字段”。
     - 周起始日、月视图最大任务数、默认时长请在“软件设置”中调整。
     - 拖动任务块可调整开始或结束日期；在日视图和周视图中可精确调整时间。

6. 甘特视图（重点：开始/结束日期）
   · 说明：以横向时间轴展示任务排期与进度，支持“年 / 季度 / 月 / 周 / 日”
     多种时间维度切换。
   · 关键字段：
     - 开始日期字段：必须是 Date 或 DateTime 类型，决定任务条起点。
     - 结束日期字段：必须是 Date 或 DateTime 类型，决定任务条终点。
     - 分组字段（可选）：用于左侧分组显示。
     - 进度字段（可选）：百分比字段，可在任务条内显示进度。
   · 重点设定：
     - 在“字段设置 / 甘特设置”中指定“开始日期、结束日期、分组字段”。
     - “显示边界”可选择“按任务边界”或“项目边界外扩 N 天”。
     - 拖拽任务条或边框可调整起止日期与时长。

7. 仪表盘视图
   · 汇总展示多张统计图表卡片，包括柱形图、折线图、饼图、环形图、KPI 卡等。
   · 每张卡片可单独设置维度字段、数值字段、图表类型与主题色。
   · “图表控制开关”可控制卡片右上角“设置/删除”按钮的显示与隐藏。
   · 右键卡片可将图表导出为 PNG 图片或复制到剪贴板。

8. 图表视图
   · 单张统计图表的独立视图。
   · 关键字段同仪表盘：维度字段 + 数值字段。
   · 可设置时间分组（按日/周/月/季度/年）以及隐藏小值标签阈值。


【四、字段类型说明】

插件会自动识别以下字段类型，您也可以在“字段设置”中手动调整：

  Text        文本
  LongText    长文本
  Number      数字（可设小数位）
  Integer     整数
  Date        日期
  DateTime    日期时间（包含小时和分钟）
  Select      单选（需预先设置选项）
  Quarter     季度
  Currency    金额（自动显示 ¥ 符号）
  Percentage  百分比
  Email       邮箱
  Phone       手机
  Url         网址
  Checkbox    勾选
  Image       图片（本地图片路径）

【特别提醒】
日历视图和甘特视图的开始/结束字段，强烈建议使用 DateTime 类型字段。
如果源数据只有日期，可在字段设置中将类型切换为 DateTime，插件会在需要时
自动补全 00:00 时间部分；若已有时间信息，则会完整保留小时和分钟。


【五、常用操作】

1. 新增记录
   点击顶部“＋ 新增”按钮，在弹出的录入界面中填写数据后保存。

2. 编辑记录
   · 表格视图：双击单元格直接编辑，按 Enter 或失去焦点后自动保存。
   · 表单/看板/画册/日历/甘特视图：选中记录后在详情面板中编辑，保存后生效。

3. 删除记录
   表格视图中选中行后右键，选择“删除行”即可。

4. 字段开关
   点击“字段开关”按钮，勾选需要在当前视图中显示的字段。

5. 字段设置
   点击“字段设置”按钮，可设置字段显示名称、类型、格式、选项、计算公式等。

6. 查找
   点击“查找”按钮，输入关键词后可在当前视图中快速定位记录。

7. 刷新
   当 Excel 源数据被外部修改后，点击“刷新”按钮重新读取最新数据。

8. 保存配置
   视图布局、字段显示、排序、分组等配置会自动保存；您也可以在功能区点击
   “保存配置”手动保存。


【六、软件设置】

点击左侧顶部的“设置”按钮，可打开软件设置面板：

  · 窗口置顶：让插件窗口始终保持在 Excel/WPS 前方。
  · 打开时最大化：每次打开插件时自动最大化窗口。
  · 图表控制开关：控制图表/仪表盘卡片右上角设置/删除按钮的显示。
  · 月视图最大任务数：日历月视图中每个日期格子最多显示几条任务。
  · 数据源：切换当前工作簿中的不同超级表。

软件设置与具体文件无关，打开任意多维表都会长期生效。


【七、常见问题】

Q1：打开插件后空白或报错？
A：请确认当前工作簿中存在至少一个超级表；并检查是否已安装 .NET 8 Desktop
   Runtime；最后可在“设置 → 关于本软件”中核对版本与部署时间。

Q2：日历视图看不到任务？
A：请进入“字段设置 → 日历设置”，检查“开始日期字段”是否已正确指定为
   Date 或 DateTime 类型字段；若使用结束日期，也请一并指定。

Q3：甘特视图任务条长度不对？
A：请检查“开始日期”和“结束日期”字段类型是否均为 Date 或 DateTime，
   并确认结束日期不早于开始日期。

Q4：字段未按预期显示？
A：检查“字段开关”是否已勾选该字段；同时检查字段设置中的“显示格式”
   是否正确（如 money、percent、datetime 等）。

Q5：如何卸载插件？
A：运行插件目录下的“卸载.bat”，或在 Excel/WPS 加载项管理中取消勾选
   “多维表分析”。
