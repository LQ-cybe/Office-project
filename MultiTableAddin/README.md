# MultiTableAddin · 多维表分析软件

> 一款运行在 **Microsoft Excel / WPS 表格** 内的多维数据分析插件：把一张普通的 Excel 超级表（`Ctrl+T`），瞬间变成支持 **表格、表单、画册、日历、甘特图、仪表盘、图表** 七大视图的多维数据工作台。

- **当前版本**：v2.9.42
- **开源协议**：[MIT License](LICENSE)
- **技术底座**：ExcelDNA 1.9 + .NET 8 + WebView2 + WPF/HandyControl

---

## ✨ 功能亮点

### 七大视图，一键切换

| 视图 | 说明 |
|------|------|
| 📋 **表格视图** | 行列展示、就地编辑、排序、分组折叠、右键插入/删除行、字段级显示开关 |
| 📝 **表单视图** | 逐条聚焦录入，上一条/下一条切换，支持「复制新增」 |
| 🖼️ **画册视图** | 卡片网格图文混排；支持图片字段 / 文件夹按字段值匹配两种图源；分组后看板式水平列布局，拖拽卡片跨列即改分组并实时保存 |
| 📅 **日历视图** | 月/周/日三档；拖拽调整起止日期（按天/15分钟吸附）；当前时间线、重叠并排、折叠提示 |
| 📊 **甘特视图** | 日/周/月/季维度切换、今天线、分组、工作日计算、年翻页 |
| 📈 **仪表盘** | KPI 指标卡 + 统计图表集中展示；首次加载按字段类型自动生成 |
| 📉 **图表视图** | 柱状/条形/折线/面积/饼图/环形图，支持维度、度量、时间粒度（年/季/月/周/日）配置 |

### 智能字段体系

- 自动识别：文本、多行文本、数字、日期、日期时间、单选、季度、金额、百分比、勾选、图片等 11 种字段类型
- 显示格式：金额（¥）、百分比、千分位、手机号分段、身份证分段
- 字段校验：必填、最值、长度、正则表达式 + 错误提示

### 视图与配置管理

- 视图右键「另存新视图 / 重命名 / 删除」，新视图完整继承分组、排序、筛选等配置
- 配置双通道保存：嵌入 Excel 深度隐藏表 `_MultiTableConfig` 和/或同目录 `{文件名}.multiview.json`，随文件移动不丢失
- 按「工作簿 + 超级表」隔离配置，多表互不干扰

### 双宿主支持

- Microsoft Excel（Office 2016 及以上）与 WPS 表格共用同一套 DLL/XLL，自动识别宿主，提供分离式安装脚本

## 🚀 快速开始（使用者）

1. 确认已安装 **.NET 8 Desktop Runtime**（Windows 10/11）
2. 完全关闭 Excel/WPS
3. 构建后进入 `dist\` 目录：
   - Excel 用户双击 `install_excel_addin.bat`
   - WPS 用户双击 `install_wps_addin.bat`
4. 打开 Excel/WPS，将数据区域按 `Ctrl+T` 转换为超级表
5. 点击 Ribbon 上的「多维表」按钮即可打开主窗口

卸载：运行对应的 `uninstall_*.bat` 即可。

## 🛠️ 源码构建（开发者）

### 环境要求

- Windows 10/11
- Visual Studio 2022 或 .NET 8 SDK
- 仓库内已附带本地补丁版 ExcelDNA 运行时（`runtime\exceldna\`），构建强依赖，请勿删除

### 构建流程

```powershell
# 编译并自动把产物复制到 dist\files
.\build_addin.ps1 -Configuration Release
```

> ⚠️ 注意：仅执行 `dotnet build` 不会更新安装目录，必须运行 `build_addin.ps1`；构建后需完全关闭 Excel/WPS 再重新运行安装脚本，否则加载的仍是旧版 DLL。

### 项目结构

```
MultiTableAddin/
├── src/MultiTableAddin/        # 插件源码
│   ├── Core/                   # 视图引擎、字段识别/校验、图表数据构建
│   ├── Views/                  # WPF 界面：表格/表单/画册/日历/甘特/仪表盘等
│   ├── TaskPane/               # 自定义任务窗格宿主
│   ├── Html/                   # WebView2 内嵌单文件页面 index.html
│   └── Resources/              # Ribbon 定义、图标、主题样式
├── runtime/exceldna/           # 本地补丁版 ExcelDNA 运行时（构建必需）
├── docs/                       # 蓝图能力说明与开发指引
├── dist/                       # 构建输出与安装入口（不入库）
├── build_addin.ps1             # 一键构建脚本
├── install_*.bat / uninstall_*.bat   # 安装/卸载脚本
└── Directory.Build.props       # 全局构建属性
```
