### BUG 修复 #1：甘特视图 月/年 维度右侧空白未对齐窗口右缘
- 现象：甘特 月、年 视图右侧轨道区右缘不贴窗口右边、留空白；日、季 正常。
- 根因：`renderGantt` 内 `setCanvasWidth(el){ el.style.width=canvasW+'px' }`（index.html ≈ 行 2972），`canvasW=totalDays*GANTT_DAY_PX`，月/年 px/天最小（month:16、year:4），数据区间不大时 canvasW 窄于 `.gantt-scroll` 可视宽 → 图表左对齐、右侧留白。日/季 px/天大（80/12）故总溢出填充、无空白。
- 修复：改为 `el.style.width='max('+canvasW+'px, 100%)'`。canvasW<可视宽时撑满 100% 消除空白；>可视宽时维持 canvasW 仍可横向滚动。百分比定位的甘特条/网格/今天线以图表实际渲染宽为基准，两种情形映射一致，不破坏条位置。
- 影响元素：axisRow / axis / chart / grid / overlay 全部经 setCanvasWidth 设置，统一生效。

### BUG 修复 #2：功能区图标黑色 → 统一强调蓝
- 现象：主区顶栏 `设置/刷新/帮助` 与 `复制全部` 等按钮图标为黑色（非主题蓝）。
- 根因：这些按钮用 `className='btn sm'` + `<span class="ic">`+SVG（`stroke="currentColor"`），基础规则 `.btn .ic`（index.html 行 24）未设 color，继承 `.btn` 的 `var(--text)`（浅色主题下近黑）。v2.9.42 仅给 `.sidebar-top .btn .ic` 与 `.view-item .ic` 上了 `--accent`，主工具条漏改。
