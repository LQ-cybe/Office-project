## v2.9.37（ConfigInspector / 2026-08-18）— #465 / #466

### 用户反馈（v2.9.36 验收后）
1. 画册视图控件高度不一**仍然存在**（#461 只修好了"列等高"，卡片没修好）
2. 选了「配置保存在 Excel 中」但**在 Excel 里找不到隐藏工作表**，想看配置结构和数据

### 关键改动
- **#465 画册分组卡片高度（#461 的真根因）**：`.kanban-col-body` 是定高 `flex-direction:column` 容器，`.gallery-card` 作为 flex item **默认 `flex-shrink:1`** → 列内卡片被按溢出量**等比压扁**，各分组卡片数不同 → 压缩比不同 → 高度不一，且压扁后不出滚动条。修复 = 一条 CSS：`.kanban-col-body>.kanban-card,.kanban-col-body>.gallery-card{flex:0 0 auto;}`（顺带覆盖看板卡片，纯防压缩不改视觉）。
- **#466 嵌入配置查看器**：`_MultiTableConfig` 用 `Visible=2`（xlSheetVeryHidden），**不出现在 Excel「取消隐藏」列表**，这是"找不到"的原因；且写隐藏表只改内存，须 `wb.Save()` 才落盘。新增软件设置 →「嵌入配置」→「查看配置结构与数据」对话框：状态行（表名/可见性/JSON 字符数/超级表数/最后使用表）+ 格式化 JSON 正文 + 操作（在 Excel 中显示 / 重新隐藏 / 复制 JSON / 保存工作簿 / 关闭，ESC 可关）。
  - C#：`ExcelAdapter.GetConfigSheetInfo()`、`SetConfigSheetVisible(bool)`（-1/2 切换 + Activate）、`SaveWorkbookFile()`（`DisplayAlerts=false` 静默保存，无路径工作簿返回 false 不弹另存为）；`HtmlMainForm` 路由 `getEmbeddedConfig`/`setConfigSheetVisible`/`saveWorkbookFile`。
