## 多维表分析软件 — Excel插件版完整实现

### 项目构建
- 使用 ExcelDNA Add-in 框架（非VSTO），更轻量部署
- 技术栈：net8.0-windows + WPF + HandyControl 3.5.1 + ExcelDNA
- 项目路径：`MultiTableAddin/src/MultiTableAddin/`

### 实现的核心模块
1. **Models.cs** — 数据模型：ViewType/FieldType枚举、FieldSchema（含类型推断）、DataRowModel、DataTableModel、ViewConfig等
2. **ExcelAdapter.cs** — Excel ListObject 读写适配器，隔离所有COM操作，批量读取/单行更新
3. **ViewEngine.cs** — 纯逻辑模块：过滤/排序/分组，输出ViewDataSet
4. **ViewConfigManager.cs** — JSON配置持久化，文件路径 `{workbook}.multiview.json`
5. **六大视图**：TableView（DataGrid双向绑定）、FormView（单记录导航）、KanbanView（拖拽看板）、GalleryView（卡片画册）、CalendarView（月历）、GanttView（甘特图）

### 编译问题修复（WPF + WinForms 命名空间冲突）
项目同时启用 `UseWindowsForms=true` 和 `UseWPF=true`，导致大量类型歧义：
- **全局别名方案**（GlobalUsings.cs）：为 Brush/Brushes/Color/Point/Rectangle/Binding/Button/ComboBox/Orientation/DragDropEffects/HorizontalAlignment/FlowDirection/MouseEventArgs/DragEventArgs 添加全局 using 别名指向 WPF 版本
- **局部别名**：UserControl 和 TextBox 需在WPF视图文件中单独声明（因 TaskPaneHostControl.cs 需用 WinForms 版本）
- **FormBlankForWpf.cs**：使用完整限定名 `System.Drawing.Color/Point/Rectangle` 替代
- **GanttView.xaml.cs**：修复 `[Canvas.LeftProperty]` 索引器语法 → 改用 `Canvas.SetLeft()/SetTop()`
- **Growl 调用**：移除 `using HandyControl.Controls;`，所有 Growl 调用改为 `HandyControl.Controls.Growl.XxxGlobal()` 完整限定
- **RuntimeHelpers**：TaskPaneHostControl.cs 添加 `using System.Runtime.CompilerServices;`
