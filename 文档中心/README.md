# 文档中心

> 多维表分析软件（MultiTableAddin）的全部项目文档按用途分类存放于此。
> 源码工程见上级目录 `MultiTableAddin\`（已发布至 https://github.com/LQ-cybe/Office-project ）。

## 目录结构

| 目录 | 内容 |
|------|------|
| `01-使用手册` | 面向使用者的功能说明：插件使用帮助、仪表盘说明、软件设置与文件设置对照 |
| `02-功能设计` | 各功能模块的设计与实现分析：字段处理、双向联动、视图结构、UI 风格、日历布局等 |
| `03-规划方案` | 技术选型与未来规划：开发规划与技术路线、桌面版独立软件方案、可行性分析 |
| `04-开发记录` | 开发过程记录：项目开发记录（任务清单）、版本更新记录、经验总结 |
| `99-归档_早期草稿` | 已被正式版文档取代的早期草稿，仅作留档，请勿在此查找最新内容 |
