# 多维表分析 — 软件设置与文件设置对照表

> 本文档说明哪些配置跟随“软件”（本机全局，保存在 localStorage），哪些配置跟随“文件”（与当前打开的 `.xlsx`/`.multiview.json` 绑定）。
> 理解这两者的区别，可以避免"每次打开同一个文件都要重新调整"的困扰。

## 1. 配置文件位置

| 层级 | 保存位置 | 影响范围 | 随文件迁移 |
|------|---------|---------|-----------|
| 软件设置 | 浏览器 localStorage（`mt_app_settings`） | 当前电脑、所有多维表文件 | 否 |
| 文件设置 | `{文件名}.multiview.json`（与 xlsx 同目录） | 仅当前文件 | 是（xlsx + json 一起复制即可） |
| 嵌入 Excel | xlsx 内的 `_MultiTableConfig` 隐藏工作表（深度隐藏，不在「取消隐藏」列表） | 仅当前文件、随 xlsx 移动 | 是（xlsx 一起复制即可） |

## 2. 软件设置（全局）

以下设置只对当前电脑生效，换电脑或清浏览器数据后会恢复默认值。

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 窗口置顶 | 关闭 | 插件窗口是否始终位于 Excel/WPS 窗口之上 |
| 打开时最大化 | 开启 | 每次打开插件窗口是否自动最大化 |
| 仪表盘主题色 | office | 仪表盘/图表视图的默认配色主题 |
| 图表标签隐藏阈值 | 0 | 数值 ≤ 该值的数据标签不显示（0 表示不隐藏） |
| 图表控制开关 | 显示 | 图表视图 / 仪表盘卡片右上角「设置/删除」按钮是否显示（含图表顶部指标区设置按钮、仪表盘指标(KPI)卡片「设置」按钮） |
| 月视图最大任务数 | 5 | 日历月视图每个日期格最多显示几条记录 |
| 周起始日 | 周一 | 日历/甘特周刻度从哪一天开始（周日~周六 任选） |
| 日程默认时长 | 30 分钟 | 日历新增/单击创建记录时的默认持续时长 |
| 可视化调整保存模式 | 自动（拖完即保存） | 甘特图拖拽调整起止/时长后的写回方式：自动=拖完立即写回工作表；手动=拖完仅暂存内存、右下角出现「保存调整」条手动写回，且切换视图/关闭软件前有未保存调整会弹确认 |
| 配置保存位置 | 两者都保存（默认） | 配置写入何处：仅嵌入 Excel 工作表 / 仅外部 JSON 文件 / 两者都保存。切换时会自动清理另一种存储（如选「仅外部文件」会删除嵌入隐藏表） |

## 3. 文件设置（跟随当前多维表文件）

以下设置保存在 `{文件名}.multiview.json` 中，随文件一起迁移，换电脑打开同一个文件时配置仍然保留。

### 3.1 字段属性

| 设置项 | 说明 |
|--------|------|
| 字段类型 | Text / Number / Date / Select / Currency / Percentage 等 |
| 显示格式 | 如 `money`、`percent`、`int`、`phone`、`datetime` 等 |
| 选项列表 | Select / Quarter 类型的下拉选项 |
| 必填 | 是否必填 |
| 最小值 / 最大值 | 数字类型字段的取值范围 |
| 步进值 | 数字字段使用上下箭头时的增量 |
| 最小长度 / 最大长度 | 文本类字段长度限制 |
| 正则验证 | 自定义正则表达式校验 |
| 错误提示 | 校验失败时显示的提示文字 |

### 3.2 视图公共状态

| 设置项 | 说明 |
|--------|------|
| 当前活动视图 | 表格 / 表单 / 画册 / 日历 / 甘特 / 仪表盘 / 图表 |
| 可见字段 | 每个视图独立保存显示哪些字段 |
| 分组字段 | 甘特、画册（分组模式）等视图的分组依据 |
| 排序字段与方向 | 每个视图独立的排序 |
| 筛选关键词 | 顶部查找框的筛选内容 |
| 字段级筛选 | 对某一列设置的关键词筛选 |

### 3.3 各视图专属配置

| 视图 | 保存的配置 |
|------|-----------|
| 表格视图 | 底部汇总行字段与计算方式、是否显示汇总行、汇总行位置（数据末尾/窗口底部） |
| 表单视图 | 字段设置（与字段属性共享） |
| 画册视图 | 图片字段、标题字段、分色字段、图片文件夹、匹配字段、图片显示模式（正常/圆形）、字段标签显隐 |
| 日历视图 | 开始/结束日期字段、标题字段、分色字段、时间步进 |
| 甘特视图 | 开始/结束日期字段、标签字段、进度字段、分组字段、着色字段、时间维度、显示边界模式、工作日-only 等 |
| 仪表盘 | 指标卡片（标题、字段、聚合方式、格式、颜色）、图表（标题、类型、维度、度量、聚合、时间维度、高度、显示标签等）、列数 |
| 图表视图 | 图表类型、维度、度量、聚合、时间维度、显示标签等 |

> **嵌入 Excel 的配置如何查看**：`_MultiTableConfig` 是深度隐藏表（不在 Excel「取消隐藏」列表）。如需查看 / 编辑，到「软件设置 → 嵌入配置 → 查看配置结构与数据」对话框，可临时在 Excel 中显示该表、复制 JSON 并保存工作簿。仅当「配置保存位置」包含「嵌入 Excel」时才会创建该表。

## 4. 快速排查"设置没保留"

| 现象 | 可能原因 | 解决方法 |
|------|---------|---------|
| 同一台电脑换文件后设置变了 | 该设置属于文件级，每个文件独立 | 正常现象，换文件后重新配置一次即可 |
| 同一文件每次打开都要重新调 | 配置未成功写入 `.multiview.json` | 检查文件是否只读、目录是否有写入权限 |
| 字段类型/步进值丢失 | 旧版本 json 缺少对应字段 | 重新打开字段设置并保存一次即可升级 |
| 汇总行位置变回默认 | 旧版本使用全局设置，现已改为文件级 | 在表格视图「视图设置」中重新选择位置并应用 |

## 5. 备份与迁移

如需把配置带到另一台电脑，只需同时复制：

- `文件名.xlsx`
- `文件名.multiview.json`

两个文件放在同一目录下即可。只复制 xlsx 不会带走视图配置。
