# 多维表分析插件使用帮助

> 适用版本：v2.9.42 及以上  
> 最后更新：2026-08-20

---

## 一、快速开始

1. **安装插件**：完全关闭 Excel/WPS 后，从 `dist\files` 目录运行安装脚本（`install_excel_addin.bat` 用于 Excel，`install_wps_addin.bat` 用于 WPS 表格）。
2. **打开数据源**：插件读取当前工作簿中的 Excel **超级表（ListObject）**。请先将数据区域按 `Ctrl+T` 转换为表。
3. **切换视图**：左侧视图栏可切换表格、表单、画册、日历、甘特、仪表盘、图表等视图。
4. **字段类型**：插件会识别文本、数字、日期、日期时间、单选、季度、金额、百分比、勾选、图片等字段类型。若识别有误，可在「字段设置」中手动调整。

## 二、各视图说明

### 1. 表格视图
- **功能**：行列展示所有记录，支持点击单元格就地编辑。
- **字段开关**：工具栏「字段开关」可控制当前视图显示的字段，不影响其它视图。
- **排序**：选择字段后点击升序/降序；再次点击取消排序。
- **分组**：在工具栏「分组」下拉选择字段后，表格会按该字段值分组显示；分组标签前显示 ▼/▶ 按钮，单击可折叠 / 展开该分组（默认全部展开）。
- **右键菜单**：在表格行上右键可「上方插入行」「下方插入行」「查看详情」「删除记录」。
- **列宽**：日期、下拉字段列已预留给编辑控件足够宽度，避免点击编辑时列宽抖动。

### 2. 表单视图
- **功能**：一次聚焦一条记录，适合逐条录入或查看详情。
- **操作**：「上一条 / 下一条」切换记录，「重置」恢复原始值，「保存」提交修改。
- **注意**：保存按钮只提交有变化的字段。

### 3. 画册视图
- **功能**：以卡片网格展示记录，适合图文混排（如产品图册、档案卡片、人员名片）。
- **设置（视图设置）**：
  - **图片字段**：选择一个「图片」类型字段，字段值即图片地址（支持本地路径 / http(s) / data URI）。
  - **标题字段**：卡片标题文字。
  - **分色字段**：按该字段值（如状态、分类）给卡片顶部加一条彩色边。
  - **图片文件夹 + 图片匹配字段**：开启「文件夹模式」——选择一个本地文件夹，并按某个字段（如产品编号、姓名）的值去匹配文件夹内图片文件名（按文件名去扩展名、忽略大小写；支持 `编号_序号` 前缀匹配），自动显示对应图片。该模式无需在表里维护图片路径。
  - **图片显示模式**：`正常（矩形）` 充满卡片图区；`圆形（居中裁剪）` 居中裁成圆形头像，适合人员 / Logo。
- **图片两种来源小结**：① 图片字段（字段值即地址）；② 文件夹匹配（按字段值匹配文件夹内文件名）。两者互斥，配了文件夹模式优先用文件夹。
  - **分组**：工具栏「分组」下拉选择分组字段后，画册**按水平列布局**展示——每组一列，列内卡片纵向排列，各列**统一高度**，记录多时列内独立垂直滚动（不会压扁卡片、也不会撑乱布局）。
  - **分组内拖拽**：分组模式下，按住卡片拖到其它分组列即改变其分组字段值，**松手实时保存**（画册分组直接复用分组列拖拽机制）。
  - **单击行为**：单击卡片仅**选中**该记录，不再自动弹出右侧详情面板（查看详情可用右键菜单或右侧面板）。
- **不分组**：默认单列网格，所有卡片按字段从左到右排列。
- **卡片尺寸**：每个卡片有最小宽高限制，数据再多也不会被压成一条线。
- **本地图片**：本地图片由插件经 C# 转 base64 显示（绕过 WebView2 对 file:// 的限制），无需手动转码。

### 4. 日历视图
- **视图切换**：工具栏「月 / 周 / 日」切换视图。若按钮未显示，请检查窗口是否过窄或重装插件。
- **添加记录**：
  - 月视图：点击日期单元格空白处，右侧会打开新建草稿，预填当天日期（若字段为日期时间则预填 09:00）。
  - 周/日视图：点击时间格空白处，右侧草稿预填对应日期时间。
  - 所有视图均需点击右侧「保存」才真正新增记录。
- **当前时间线**：红色时间线显示在今天的日期列内，圆点位于当前列左侧。
- **拖拽调整（月视图）**：按住任务条拖动即可调整日期，自动按整天对齐递增：
  - 拖**左缘**（事件条左侧 8px）→ 调整**开始日期**；
  - 拖**右缘**（事件条右侧 8px）→ 调整**结束日期**（无结束日期字段时自动生成 1 天时长）；
  - 拖**中部**→ 整体平移任务（开始与结束同时偏移，占用时长不变）；
  - 支持**横向（按天）+ 纵向（按周，每行 7 天）**拖拽，松手即按整格对齐。
- **拖拽调整（周/日视图）**：按住事件条**上下拖动**实时调整开始/结束时间（默认按 15 分钟吸附）；拖**顶部**只改开始时间、拖**底部**只改结束时间（时长）。
  - **日视图不允许重叠**：若两个任务时间冲突，会自动**水平并排**显示在同一时间窗口内；
  - **周视图允许重叠**：任务可叠放显示，不做并排处理。
- **折叠提示**：月视图单日超过设定条数（见设置「月视图每格显示任务数」，默认 5 条）时，显示前 N 条并在最后显示「还有 N 条记录」。
- **设置**：「日历设置」可选择开始日期字段、结束日期字段（可选）、标题字段。
- **悬停提示**：鼠标悬停事件条（日视图事件 / 月视图分段）会显示「标题 + 起止日期范围（YYYY-MM-DD → YYYY-MM-DD）」，与甘特条悬停内容完全一致。

### 5. 甘特视图
- **前提**：数据必须包含日期或日期时间字段。
- **配置**：点击「甘特图配置」设置开始日期、结束日期、标题显示字段、颜色模式、自定义颜色、是否仅计算工作日。
- **字段开关**：甘特左侧标签会跟随工具栏「字段开关」显示或隐藏字段信息；未开启任何字段时回退到标题字段。
- **分组**：可选择一个字段作为分组字段；按进度等百分比字段分组时，分组头会显示为格式化的百分比（如 50%）；分组标签前显示 ▼/▶ 按钮，单击可折叠 / 展开该分组（默认全部展开）。
- **今天线**：红色竖线标识今天位置，贯穿图表区。
- **维度切换**：工具栏「日 / 周 / 月 / 季」切换时间跨度。
- **年切换按钮**：右上角「◀ / ▶」按钮**常驻显示**，可前后翻年；季度视图会按数据所在年份居中展示，避免任务条落在可视窗口之外而空白。

### 6. 仪表盘视图
- **指标**：点击「＋ 指标」添加统计卡片，可设置统计字段、聚合方式（求和/计数/平均/最大/最小/去重计数）、显示格式、颜色。
- **图表**：点击「＋ 图表」添加图表，可设置图表类型、维度字段、度量字段、聚合方式、时间维度、高度、是否显示标签。
- **显示/隐藏标签**：工具栏「隐藏标签 / 显示标签」可一键切换所有图表的数据标签和分类标签；也可在单个图表的「设置」中单独控制。
- **条形图**：维度字段为空时，若设置了时间维度，插件会自动使用第一个日期字段作为分组依据。

### 7. 视图管理（左侧侧栏视图项右键菜单）
- **打开方式**：在左侧视图栏的任一视图项上**右键**，弹出菜单：**另存新视图 / 重命名 / 删除**。
- **适用范围**：所有视图（自带基础视图 + 用户另存的视图）都能「另存新视图」。
- **保护规则**：「重命名」「删除」仅对**用户自己另存的视图**可用；7 类自带基础视图（表格 / 表单 / 画册 / 日历 / 甘特 / 仪表盘 / 图表）受保护，菜单项置灰，点击会提示「自带视图不可删除 / 不可改名」。
- **另存新视图（弹框输名）**：点击后立即弹出输入框，预填按「类型 + 序号」生成的建议名（见下方命名规律），确认即创建并切换到新视图，无需事后手动改名；空名 / 同名会被拦截提示。
- **命名规律**：去掉「视图」二字，按类型基名 + 序号递增——基名取视图类型标签，如 表格1、表格2、表格3；画册1… 依次递增，自动避开已用序号。
- **残留视图也可删**：早期版本复制产生的 `copy-` / `gantt-` 前缀残留视图（缺 `userView` 标记），现按前缀兜底判定为用户视图，可正常重命名 / 删除。
- **悬停看全名**：左侧栏宽度有限会截断长名称（省略号），把鼠标悬停在视图项上即可显示完整名称。
- **颜色区分**：自带基础视图的名称与图标用强调蓝；用户另存的新视图名称与图标不显示强调色（用常规文字色），仅以「自带视图 / 用户视图」之间的一条分隔线与自带视图区分；用户视图被选中（激活）时仍显示蓝色。
- **持久化**：另存 / 重命名 / 删除都会保存；新视图完整继承被复制视图的分组、字段可见性、排序、筛选等配置，并随文件一起保存。

## 三、字段设置与显示格式

### 1. 字段类型
| 类型 | 说明 |
|------|------|
| 单行文本 | 普通文本 |
| 多行文本 | 长文本，编辑时自动增高 |
| 数字 / 整数 | 数值输入 |
| 日期 | 日期选择器 |
| 日期时间 | 日期时间选择器，支持拖动调整时间 |
| 单选 | 下拉选择，需在字段设置中维护选项 |
| 季度 | 固定四个季度选项 |
| 金额 | 显示为 ¥ 格式 |
| 百分比 | 存储为小数（0.5 表示 50%），显示为 50.00% |
| 勾选 | 复选框 |
| 图片 | 显示图片路径或预览 |

### 2. 显示格式（format）
在「字段设置」的「显示格式」中可填写：
- `money`：金额格式（¥1,234.56）
- `percent`：百分比格式
- `int`：整数千分位
- `datetime`：日期时间（对 DateTime 字段默认即显示日期时间）
- `phone`：手机号 3-4-4 分段
- `idcard`：身份证分段

### 3. 必填 / 最值 / 长度 / 正则
- 数字字段可设最小值、最大值。
- 文本字段可设最小长度、最大长度、正则表达式及错误提示。

## 四、图表设置详解

### 1. 图表类型
- **柱状图 / 条形图 / 折线图 / 面积图**：需维度字段和度量字段。
- **饼图 / 环形图**：按维度字段占比展示；环形图中间为空白圆。

### 2. 维度字段
- 用于分组的字段，如部门、负责人、状态等。
- 条形图 / 柱状图至少需要一个维度字段或时间维度。

### 3. 度量字段
- 需要统计的数值字段，如项目费用、盈利、完成进度等。
- 选择「计数」聚合时，可不指定度量字段。

### 4. 时间维度
- 按年 / 季度 / 月 / 周 / 日 对日期字段分组。
- 若维度字段为空但选择了时间维度，插件会自动使用第一个日期字段。

### 5. 标签显示
- 开启时显示分类标签和数值标签。
- 关闭时仅保留图形，适合简约展示。

## 五、常见问题与注意事项

1. **改了源码后没有看到效果**  
   仅 `dotnet build` 不会更新安装目录，必须在 `tools\` 下执行 `build_addin.ps1 -Configuration Release`（自动编译并把产物复制到 `dist\files`），然后完全关闭 Excel/WPS 后重新运行安装脚本。仅重新编译而不重装，加载的仍是旧版 DLL。

2. **日历中日切换按钮不见了**  
   确保窗口宽度足够；若仍不显示，请重新安装插件并确认版本为 v2.9.10+。

3. **甘特图左侧标签显示不正确**  
   检查字段开关是否开启了需要显示的字段；检查分组字段类型是否与数据一致（如百分比字段需设置为「百分比」类型）。

4. **仪表盘条形图混乱**  
   检查维度字段是否为空、度量字段和聚合方式是否匹配。若使用时间维度，确保数据中有日期字段。

5. **日期时间字段只显示日期**  
   在「字段设置」中将类型改为「日期时间」；如未设置格式，默认显示日期时间。

6. **表格列宽点击后抖动**  
   v2.9.0+ 已增加日期/下拉列的默认宽度和额外内边距；如仍抖动，可手动拖动列宽后保存视图。

7. **插件关于窗口**  
   点击关于窗口可查看当前版本号、编译时间、DLL 路径，用于确认加载的是否为最新版本。

8. **配置保存在哪里**  
   默认「两者都保存」：配置同时写入 xlsx 隐藏工作表 `_MultiTableConfig`（深度隐藏）和同目录外部文件 `{文件名}.multiview.json`。可在「软件设置 → 配置保存位置」切换为「仅嵌入 Excel / 仅外部文件 / 两者都保存」。改为「仅外部文件」会自动删除嵌入隐藏表；改为「仅嵌入 Excel」会自动删除外部 JSON。

9. **想在 Excel 里查看 / 编辑嵌入的配置**  
   嵌入的 `_MultiTableConfig` 表是深度隐藏（xlSheetVeryHidden），不在 Excel 右键「取消隐藏」列表里。请到「软件设置 → 嵌入配置 → 查看配置结构与数据」对话框：可查看配置 JSON、临时在 Excel 中显示该表、重新隐藏、复制 JSON，并「保存工作簿」把配置落盘。

10. **移动文件后配置会失效吗**  
   不会。配置以「当前工作簿路径」为键加载：隐藏表随 xlsx 一起移动；外部 JSON 按同目录 + 文件名匹配。配置记录里的 `SourceFile` 仅存文件名（不再存完整绝对路径），移动文件不会导致加载失败。

## 七、版本标识

- 版本号：`2.9.42`
- 发布日期：`2026-08-20`

> 本版本及近期主要变更（相对早期版本）：
> - **看板视图下线（v2.9.42）**：产品不再提供独立的「看板」视图类型。原看板的分组拖拽能力已并入「画册」——画册分组模式下拖拽卡片跨列即改分组字段、松手实时保存。旧配置中遗留的 Kanban 视图打开时自动迁移为画册视图。
> - **图标统一为强调蓝（v2.9.42）**：窗口左上角品牌点、功能区按钮图标、视图切换列表的图标与名称统一为强调蓝（`#3370FF`），深蓝（`--accent-dark`）仅保留作标题 / 大块底色，不再用于小图标。
> - **列宽自适应 / 复制新增 / 分组折叠（v2.9.42）**：表格视图列宽恢复自适应；表单「保存」左侧新增「复制新增」按钮（保存当前记录并带入字段值新建一条）；表格与甘特视图分组标签前新增 ▼/▶ 按钮，单击折叠 / 展开分组（默认全部展开）。
> - **界面图标改深蓝（v2.9.39，已在 v2.9.42 改为强调蓝）**：v2.9.39 曾将窗口左上角品牌点、功能区按钮图标改为深蓝（`--accent-dark`），该做法在 v2.9.42 已改为统一强调蓝（`#3370FF`）。
> - **日历悬停对齐甘特（本轮）**：日历日事件 / 月分段悬停内容改为与甘特条一致——「标题 + 起止日期范围（YYYY-MM-DD → YYYY-MM-DD）」。
> - **画册吸收看板分组拖拽（v2.9.39，看板视图已于 v2.9.42 下线）**：画册分组模式下可直接拖拽卡片到其他分组列、松手实时保存；单击卡片仅选中、不再自动弹右侧详情面板。看板视图类型已在 v2.9.42 移除，其分组拖拽能力并入画册分组模式。

## 八、运行环境与 WPS 兼容性

本插件基于 **Excel-DNA（.NET 8 + WebView2）** 构建，Excel 与 WPS 表格均作为宿主受支持。

### 1. 支持的宿主

| 宿主 | 安装脚本 | 宿主识别 | 说明 |
|------|----------|----------|------|
| Microsoft Excel | `install_excel_addin.bat` | 显示 `Microsoft Excel` | 通过 Excel-DNA 标准加载，功能完整 |
| WPS 表格（WPS ET） | `install_wps_addin.bat` | 显示 `WPS ET` | 通过 `ExcelDnaUtil.IsET` 自动识别，加载逻辑与 Excel 一致 |

> 两套宿主共用同一份 `MultiTableAddin.dll` 与 `*.xll`，仅安装注册入口不同。

### 2. 本机实测的 Office 参数

以下为开发/测试环境（Windows + Office 16.0 分支）实际加载时记录的真实参数：

| 参数 | 实际取值 |
|------|----------|
| 宿主显示名 | `Microsoft Excel` |
| 进程可执行文件 | `C:\Program Files\Microsoft Office\Root\Office16\EXCEL.EXE` |
| Office 版本分支 | `Office16`（对应 `ExcelDnaUtil.ExcelVersion = 16.0`） |
| 运行框架 | .NET 8（`net8.0-windows`） |
| UI 承载 | WebView2 加载内嵌于 DLL 的单文件 `index.html` |

> 说明：`Office16` 目录与 `ExcelVersion = 16.0` 是 Office 2016 / 2019 / 2021 / Microsoft 365 的统一注册表分支，插件面向该分支（即 Office 2016 及以上）开发与验证。WPS 表格通过独立的 `et.exe` 进程加载，由 `ExcelDnaUtil.IsET` 判定，不依赖上述 Office 路径。

### 3. 数据源要求

插件读取当前工作簿中的 **Excel 超级表（ListObject）**。无论 Excel 还是 WPS，请先将数据区域按 `Ctrl+T` 转换为表，插件方可识别字段与记录。
