# 多维表分析插件 — 版本更新记录

> 对比基准：**2026-08-14 版本 v2.9.19（GanttInteractTune）**  
> 当前版本：**v2.9.42（StablePath / 2026-08-20）**  
> 文档生成日期：2026-08-21

---

## 一、更新概述

本次更新围绕「**看板视图合并至画册视图**」与「**分组折叠 / 展开**」两条主线展开，并顺带统一图标配色、修复列宽自适应与新增表单「复制新增」。视图类型由 8 种精简为 7 种，功能不降反升——原看板的分组拖拽能力完整保留在画册分组模式中。

| 维度 | 2026-08-14（v2.9.19） | 当前（v2.9.42） |
|------|----------------------|----------------|
| 视图总数 | 8 种（含独立看板） | 7 种（看板并入画册） |
| 看板视图 | 独立视图存在 | 已下线，能力并入画册 |
| 分组折叠 | 不支持 | 表格 / 甘特支持 ▼/▶ 折叠展开 |
| 图标配色 | Tabler 图标，深蓝在小图标下近似黑 | 统一强调蓝 `#3370FF` |
| 表格列宽 | 出现过不自适应 | 恢复自适应，编辑不抖动 |
| 表单新增 | 仅「保存」 | 「复制新增」+「保存」 |

## 二、核心变更（重点）

### 1. 看板视图合并至画册视图

**背景**：看板与画册长期功能重叠（都做卡片 + 分组展示），维护两套渲染与拖拽逻辑成本高、用户也容易混淆该用哪个。

**现在的行为**：
- 产品**不再提供独立的「看板」视图类型**，视图切换列表不再出现「看板视图」。
- 原看板的核心能力**完整并入画册**：
  - 画册分组模式复用看板式 `.kanban-cols / .kanban-col` 水平列布局；
  - 分组内**拖拽卡片跨列即改分组字段值，松手实时保存**（复用 `enableKanbanDrag` 机制）；
  - 单击卡片仅**选中**该记录，不再自动弹右侧详情面板（与看板原行为一致）。
- **向下兼容**：旧配置中遗留的 `Kanban` 视图，打开时**自动迁移为画册视图**，用户无需手动修改任何 `.multiview.json`。

**视图清单变化**：

| 旧（8 种） | 新（7 种） |
|-----------|-----------|
| 表格 / 表单 / **看板** / 画册 / 日历 / 甘特 / 仪表盘 / 图表 | 表格 / 表单 / 画册 / 日历 / 甘特 / 仪表盘 / 图表 |

> 演进节点：v2.9.39 画册开始吸收看板分组拖拽 → v2.9.40 删除 `renderKanban` 函数、看板路由改走画册 → v2.9.41 遗留 Kanban 配置自动迁移 → v2.9.42 文档全面下线「看板视图」表述。

### 2. 分组折叠 / 展开功能（新增）

**问题**：表格、甘特按字段分组后，分组一多，页面被长分组占满，难以聚焦目标分组。

**现在的行为**：
- 表格视图、甘特视图在**每个分组标签前**新增 `▼ / ▶` 按钮：
  - 单击 `▼` → **折叠**该分组（标签切到 `▶`）；
  - 再次单击 `▶` → **展开**该分组；
  - **默认全部展开**。
- 甘特按百分比字段分组时，分组头仍按格式化百分比（如 `50%`）显示，折叠/展开逻辑一致。

**位置**：工具栏「分组」下拉选定字段后自动启用。

### 3. 图标配色统一为强调蓝（顺带优化）

- v2.9.42 起，窗口左上角品牌点、功能区按钮图标、视图切换列表的图标与名称，统一为**强调蓝 `#3370FF`**；
- 深蓝变量 `--accent-dark` 仅保留作标题 / 大块底色，**不再用于小图标**（此前深蓝在小图标下肉眼近似黑，用户报"图标是黑色"）。

## 三、相对 8 月 14 日版本的功能升级

> 以下为 v2.9.19（2026-08-14）之后陆续交付的能力，按主题归类。

### 视图与交互
- **画册分组**：水平列布局 + 拖拽改分组值（源自看板合并），各列统一高度、列内独立垂直滚动，不再压扁卡片。
- **视图侧栏右键菜单**：另存为新视图（所有视图）、重命名 / 删除（仅用户视图，自带 7 类基础视图受保护）。
- **月视图重构**：悬浮分段渲染 + 手柄拖拽 + 跨周处理；任务块支持左右拖动调整起止日期、按天吸附；选中高亮卡顿修复；`+N 更多` 显示与点击修复；空周最小高度压缩。
- **日历交互增强**：月视图任务横向拖动调整起止；周 / 日视图选中任务高亮边框可见；日视图下列不再填充颜色；月 / 周 / 日视图深蓝边框统一；关闭"单击任务切换视图"，仅日/周/月按钮切换；月视图最大任务数纳入全局设置。
- **甘特增强**：年 / 季 / 月 / 周 / 日多维度 + 今日红线 + 独立横向平移 + 显示边界（飞书模式 + 外扩 N 天）；甘特条两端 resize 手柄；行高控制（紧凑 / 正常 / 宽松）；字段设置与光标列联动。
- **查找与搜索**：查找结果样式对齐日历列表；表单 / 日历支持搜索结果列表；表格单击未改数据不再误报"保存成功"。
- **窗口体验**：打开默认最大化（修复闪烁缩回）；窗口默认最大化 + 月视图任务数全局化。

### 字段与设置
- **批量字段属性编辑器**：暴露更多可编辑属性，宽度加宽并与主窗口风格统一。
- **按指定字段自动分色**：按字段值自动配色，减少手动设置。
- **设置体系收敛**：软件设置 / 文件设置分离更清晰；配置可嵌入 Excel 隐藏工作表（VeryHidden），支持保存位置开关；`SourceFile` 仅存文件名，移动文件后配置不失效。
- **日期时间控件**：默认开启 + 浅蓝选中色 + 滚轮加速；所有 DatePicker 使用处统一替换。

### 导出与文档
- 仪表盘 / 图表导出裁剪优化、图表控制开关；帮助信息补充 WPS 适配文案；新增画册 / 看板结构说明、UI 布局分析、桌面独立软件设计等文档。

## 五、兼容与升级说明

1. **旧版看板配置自动迁移**：含 `Kanban` 视图的 `.multiview.json` 打开时自动转为画册视图，无需手动处理。
2. **视图总数变化不影响既有配置**：表格 / 表单 / 日历 / 甘特 / 仪表盘 / 图表 的现有配置全部保留；仅看板一项被合并。
3. **构建校验**：`node check-js-syntax.js` → `dotnet build -c Release` → 拷贝 DLL 至 `dist/files` → `python verify-build.py` 全部通过（565 OK / 0 FAIL，exit 0）。
4. **升级方式**：关闭 Excel/WPS 后，从 `dist\files` 重新运行 `install_excel_addin.bat` / `install_wps_addin.bat` 即可。
