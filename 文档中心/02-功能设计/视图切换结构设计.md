# 视图切换结构设计说明

> 本文档记录「多维表分析」插件前端（WebView2 + 单文件 HTML）中，左侧视图切换栏与顶部视图工具条的实现方式，便于在其他项目中复用该模式。

---

## 1. 设计目标

- **视图切换入口唯一**：只在左侧边栏显示视图列表，顶部不再显示视图页签。
- **视图与状态解耦**：每个视图拥有独立的 `visibleFields`、`groupBy`、`sort` 等配置；切换视图时恢复该视图自己的状态。
- **工具栏跟随视图**：顶部工具条只放「当前视图需要的功能按钮」，并左对齐。
- **右侧抽屉共用**：详情、字段设置等辅助面板以右侧抽屉形式出现，不遮挡主视图。

## 4. 渲染流程

### 4.1 打开数据源

`openTable(sheet, table)` 从 C# 获取字段、数据、配置后：

1. 恢复或保留 `activeViewId`（切换数据源时保持在当前视图）。
2. 用**当前视图自己的 `visibleFields`** 初始化 `state.visibleFields`。
3. 调用 `renderSidebar()`、`renderViewbar()`、`renderContent()`。

```js
var tv = state.views.find(v=>v.viewId===prevId)
      || state.views.find(v=>v.viewType==='Table')
      || state.views[0];
state.activeViewId = tv ? tv.viewId : null;
state.visibleFields = (tv && tv.visibleFields && tv.visibleFields.length)
      ? tv.visibleFields.slice()
      : (d.visibleFields||[]).slice();
```

### 4.2 左侧视图切换栏

```js
function renderSidebar(){
  state.views.forEach(v => {
    var it = document.createElement('div');
    it.className = 'view-item' + (v.viewId===state.activeViewId?' active':'');
    it.textContent = v.viewName;
    it.addEventListener('click', function(){
      state.activeViewId = v.viewId;
      // 切换视图时恢复该视图状态
      state.visibleFields = v.visibleFields.slice();
      state.filter=''; state.sortField=null; state.sortOrder=null;
      renderSidebar(); renderViewbar(); renderContent();
    });
  });
}
```

### 4.3 顶部视图工具条

`renderViewbar()` 不再渲染视图页签，只根据当前视图类型渲染功能按钮：

- 表单视图：「新增」「字段设置」
- 仪表盘：「＋ 图表」「＋ 指标」
- 其他视图：公共工具（新增、字段开关、查找、排序、分组、视图设置）

```js
function renderViewbar(){
  var tools = document.createElement('div'); tools.className='tools';
  var type = activeViewType();
  if(type==='Form') { /* 表单按钮 */ }
  else if(type==='Dashboard') { /* 仪表盘按钮 */ }
  else { renderCommonTools(tools, type); }
  $('viewbar').appendChild(tools);
}
```

### 4.4 主内容区

```js
function renderContent(){
  closeDetailPanel();
  var type = activeViewType();
  if(type!=='Form') closeSettingsPanel();
  if(type==='Table') renderTable();
  else if(type==='Form') { renderForm(); if(!settingsOpen) showFieldSettings(); }
  else if(type==='Kanban') renderKanban();
  // …
}
```

## 5. 视图配置持久化

`saveConfig()` 把当前活动视图的 `visibleFields`、`sort` 写回配置，并回写各视图的专属配置：

```js
function saveConfig(){
  var cfg = JSON.parse(JSON.stringify(state.config));
  var av = cfg.views.find(v=>v.viewId===state.activeViewId) || cfg.views[0];
  if(av){
    av.visibleFields = state.visibleFields.slice();
    av.sort = state.sortField ? [{field:state.sortField, order:state.sortOrder}] : [];
  }
  // 回写 cardMeta / calendarConfig / ganttConfig 等
  state.views.forEach(sv => {
    var cv = cfg.views.find(x=>x.viewId===sv.viewId);
    if(cv){
      cv.groupBy = sv.groupBy;
      cv.cardMeta = sv.cardMeta;
      cv.calendarConfig = sv.calendarConfig;
      cv.ganttConfig = sv.ganttConfig;
      cv.chartConfig = sv.chartConfig;
      cv.dashboardConfig = sv.dashboardConfig;
      cv.visibleFields = sv.visibleFields;
    }
  });
  api.call('saveConfig', {json: JSON.stringify(cfg)});
}
```

## 6. 右侧抽屉

- `#detailPanel`：记录详情/编辑，由看板、画册、日历、甘特、表格右键菜单打开。
- `#settingsPanel`：字段设置，在表单视图默认打开。

打开/关闭：


---

## 7. 复用要点

1. **视图列表只放侧边栏**，顶部只放当前视图的工具按钮，避免入口重复。
2. **切换视图时恢复该视图状态**，避免所有视图共享同一份 `visibleFields` 导致互相干扰。
3. **配置保存以活动视图为中心**，而不是固定写回表格视图。
4. **右侧抽屉共用**，减少弹窗层级；切换视图时自动关闭不属于当前视图的抽屉。
5. **C# 端只负责读写 Excel 和保存配置**，所有视图逻辑在 JS 端完成。
