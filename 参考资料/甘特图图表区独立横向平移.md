# 甘特视图：图表区独立横向平移（滚动条）设计
## 功能价值
仅平移右侧时间轴与甘特进度条，左侧任务列表保持冻结，保证任务名称与进度条始终对应，适合跨月、跨年长周期项目查看远期/历史排期。

## 适用与不适用场景
1. 适用：项目周期长，时间跨度大，需要查看远离当前时间的历史、未来排期。
2. 弱化场景：任务全部集中在短周期（几周内），时间轴可以完整显示在窗口，此时滚动条自动隐藏。

## 开发约束
1. UI分为左右双容器：左侧任务网格、右侧甘特画布；
    - 横向滚动：仅右侧画布生效；
    - 垂直滚动：左右容器滚动位置必须双向同步，防止行与进度条错位。
2. 时间粒度切换（周/月/季）时，保留当前视口对应的时间位置，禁止直接重置到时间轴起点。
3. 交互配套：底部滚动条、画布鼠标拖拽平移、「今天」定位按钮、左右翻页按钮。
4. 滚动条按需渲染：时间轴未超出可视区域时，隐藏滚动条。
5. 该操作仅修改视图视口，**不修改任何任务原始日期数据**。

## 取舍方案（备选）
如果开发成本过高，可移除独立滚动条，保留画布拖拽+翻页按钮；缺点普通用户不容易发现拖拽操作。

# 甘特视图：横向滚动条总时间范围计算规则
> scrollTotalMin / scrollTotalMax：横向滚动条可拖动的最左、最右边界，不等于任务本身最小/最大日期。

## 两种模式
### 模式1：严格任务边界（极简模式，开关可关闭缓冲）
scrollTotalMin = 全部任务最小开始日期
scrollTotalMax = 全部任务最大结束日期
特点：不做额外时间预留；任务条紧贴边界；适合只读预览；缺点：拖拽修改任务时间容易滚到边界无法继续拖动。

### 模式2：缓冲+粒度对齐（默认模式，对标飞书/WPS多维表）
1. 过滤空日期，计算原始数据区间 dataMin、dataMax。
2. 根据项目总时长，向前、向后增加时间缓冲（固定天数或者百分比）。
3. 根据当前时间粒度（周/月/季/年），将得到的时间对齐至自然刻度边界（周一、每月1日、季度首日）。
4. 输出 scrollTotalMin、scrollTotalMax，作为滚动条完整可滚动范围。

## 边界处理
1. 无有效任务：使用默认时间窗口，例如以今天为中心前后6个月。
2. 仅单条任务：仍然向外增加缓冲，避免时间轴过窄。
3. 切换时间粒度：会重新计算scrollTotalMin/max，但**保留用户当前正在查看的时间视口，禁止强制跳转到最左侧**。

## 关键区分
1. scrollTotalMin/max：滚动条可以滑动的极限总范围。
2. viewPortMin / viewPortMax：屏幕上当前看得见的时间区间，由滚动条滑块位置决定。
> 平移操作只修改viewPort，不改变scrollTotal总范围。
