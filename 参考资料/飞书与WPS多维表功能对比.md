# 飞书多维表格 vs WPS 多维表格 功能对比文档

> 最后更新：2026-08-07
> 对比对象：飞书多维表格（Lark Bitable）与 WPS 多维表格（WPS AirTable）

---

## 一、关于"仪表盘"问题的直接回答

**飞书多维表格是有仪表盘功能的。**

飞书多维表格的仪表盘并不是一种"视图类型"，而是一个**独立的导航组件**，位于多维表格左侧导航栏中，与"数据表"平级。用户可以在同一个多维表格文件中创建多个仪表盘页面，每个仪表盘页面可自由添加多种图表和组件 [$TRAE_REF](https://www.feishu.cn/hc/zh-CN/articles/161059314076)。

飞书的"视图"特指数据表内的展示形式（表格、看板、日历、画册、甘特、表单），而仪表盘是独立于数据表之外的数据可视化看板 [$TRAE_REF](https://www.feishu.cn/hc/zh-CN/articles/360049067931)。

WPS 多维表格同样拥有仪表盘功能，在数据表之外提供可视化看板页面，支持柱状图、条形图、柱线图、排行榜等多种图表类型 [$TRAE_REF](https://forum.wps.cn/topic/79376)。

**结论：两者都有仪表盘，功能定位基本一致，都是独立于视图之外的数据可视化层。**

## 二、整体定位对比

| 维度 | 飞书多维表格 (Bitable) | WPS 多维表格 |
|------|----------------------|-------------|
| 所属生态 | 飞书（Lark）企业协作平台 | WPS Office / WPS 365 |

| 移动端支持 | 支持查看和编辑（部分功能受限） | 支持查看和编辑 |
| 开放程度 | 完善的 OpenAPI + Webhook + SDK | 提供 WPS 开放平台 API |

## 三、视图类型对比

### 视图类型一览表

| 视图类型 | 飞书多维表格 | WPS 多维表格 | 说明 |
|---------|:-----------:|:------------:|------|
| 表格视图 (Grid/Table) | ✅ | ✅ | 基础数据表视图，两者都支持 |
| 看板视图 (Kanban) | ✅ | ✅ | 按分组列拖拽管理任务 |
| 画册视图 (Gallery) | ✅ | ✅ | 以卡片形式展示记录 |
| 日历视图 (Calendar) | ✅ | ✅ | 按日期展示记录 |
| 甘特视图 (Gantt) | ✅ | ✅ | 时间线项目管理视图 |
| 表单视图 (Form) | ✅ | ✅ | 数据收集表单 |
| 查询视图 (Query) | ❌ | ✅ | WPS 独有，类似数据库查询条件筛选视图 [$TRAE_REF](https://open.wps.cn/documents/app-integration-dev/wps365/server/dbsheet/views/get-view.html) |
| 仪表盘 (Dashboard) | ✅（独立组件） | ✅（独立组件） | 非视图类型，而是独立的数据看板 |

### 飞书视图功能特点

飞书多维表格支持 **6 种视图类型**：表格视图、看板视图、日历视图、画册视图、甘特视图和表单视图。所有视图共享同一数据源，可一键切换 [$TRAE_REF](https://www.feishu.cn/hc/zh-CN/articles/360049067931)。

- **看板视图**：支持按单选字段分组，卡片可拖拽移动，自动更新分组字段值
- **日历视图**：支持按日期字段展示，可切换月视图，支持拖拽调整日期
- **甘特视图**：支持设置开始/结束日期字段，支持任务依赖关系设置，支持拖拽调整时间
- **画册视图**：以卡片形式展示，支持设置封面图片字段
- **表单视图**：生成独立分享链接，支持字段必填设置

### WPS 视图功能特点

WPS 多维表格支持 **7 种视图类型**：表格视图、看板视图、画册视图、表单视图、甘特视图、查询视图，以及独立的仪表盘组件 [$TRAE_REF](https://open.wps.cn/documents/app-integration-dev/wps365/server/dbsheet/views/get-view.html)。

- **查询视图 (Query)**：WPS 独有功能，类似数据库 SQL 查询，可设置复杂筛选条件组合
- **看板视图**：功能与飞书类似，支持拖拽分组
- **甘特视图**：支持时间线展示和任务依赖
- 日历视图：支持按日期展示记录

### 飞书仪表盘核心优势

飞书仪表盘功能非常强大，支持 **20+ 种组件类型**，包括图表类、指标类、文本类、交互类和布局类组件 [$TRAE_REF](https://www.feishu.cn/hc/zh-CN/articles/161059314076)：

1. **分组聚合**：柱状图、折线图、散点图等图表支持按字段分组聚合统计
2. **图表联动**：点击图表中的数据可联动筛选其他组件
3. **TopN 筛选**：只展示排名前 N 的数据
4. **数据明细下钻**：点击图表数据点可查看底层记录明细
5. **切片器**：跨多个组件统一筛选数据
6. **组合布局**：自由排列和嵌套组件
7. **权限跟随**：仪表盘数据可根据访问者权限范围展示

### WPS 仪表盘特点

WPS 多维表格的仪表盘支持柱状图、条形图、柱线图、排行榜图等常见图表类型 [$TRAE_REF](https://forum.wps.cn/topic/79376)，功能相对飞书更加精简：

1. 支持基础图表类型（柱状图、条形图、折线图、柱线图等）
2. 支持排行榜图
3. 支持在仪表盘中嵌入表格视图组件
4. 支持组件缩放（用户反馈正在优化中）
5. 组件高度目前需手动调整，暂不支持自适应 [$TRAE_REF](https://forum.wps.cn/topic/77689)

### 飞书权限特点

飞书多维表格的高级权限体系非常完善 [$TRAE_REF](https://www.feishu.cn/hc/zh-CN/articles/161059314076)：

## 九、核心差异总结

### 飞书多维表格的独有优势

1. **仪表盘功能更强**：20+ 种组件类型，支持分组聚合、图表联动、TopN 筛选、切片器、透视表等高级分析功能
2. **字段类型更丰富**：邮箱、URL、进度条、评分、地理位置、群组、条码、按钮等特有字段
3. **查找引用功能**：可从关联表提取指定字段值，实现跨表数据汇总
4. **应用搭建模式**：可将多维表格包装为独立应用
5. **生态集成更深**：与飞书消息、审批、日历、文档等全链路打通
6. **模板市场**：丰富的官方和社区模板
7. **AI 集成更成熟**：与 DeepSeek 等大模型深度集成

### WPS 多维表格的独有优势

1. **查询视图 (Query)**：独有视图类型，支持复杂查询条件组合
2. **离线编辑**：WPS 客户端支持离线编辑后同步
3. **Python 扩展**：原生支持 Python 脚本扩展
4. **与 WPS Office 深度集成**：与 WPS 文字、演示、表格等办公套件无缝衔接
5. **本地化优势**：对国内政企用户更友好，符合信创要求
6. **打印功能**：支持自动化打印（权限控制中）

## 十、功能一致性结论

### 两者是否一样？

**不完全一样，但核心功能高度相似。**

| 对比维度 | 一致性 | 说明 |
|---------|--------|------|
| 基础架构 | ⭐⭐⭐⭐⭐ 完全一致 | 数据表-视图分离架构 |
| 视图类型 | ⭐⭐⭐⭐ 高度一致 | 飞书6种 + WPS 7种（含独有查询视图） |
| 仪表盘 | ⭐⭐⭐ 部分一致 | 两者都有，但飞书组件类型远多于 WPS |
| 字段类型 | ⭐⭐⭐ 部分一致 | 基础字段一致，飞书高级字段更丰富 |
| 自动化 | ⭐⭐⭐⭐ 高度一致 | 触发器+动作模式，生态集成各有侧重 |
| 权限管理 | ⭐⭐⭐⭐ 高度一致 | 均支持行级权限，飞书额外支持字段级权限 |
| 开放 API | ⭐⭐⭐⭐ 高度一致 | 均提供完整 REST API |
| AI 能力 | ⭐⭐⭐⭐ 高度一致 | 两者均支持 AI 字段和 AI 内容生成 |

### 总结

1. **核心功能基本一致**：两者都采用数据表-视图分离架构，支持表格/看板/画册/日历/甘特/表单六大视图，都有仪表盘，都支持自动化和行级权限
2. **飞书更全面**：仪表盘组件更丰富（20+种 vs WPS 的基础图表），字段类型更多，查找引用、应用搭建等高级功能更完善
3. **WPS 更轻量**：独有查询视图，支持离线编辑和 Python 扩展，与 WPS Office 套件深度集成
4. **生态差异是关键**：飞书背靠飞书企业协作生态，WPS 背靠 WPS Office 办公套件生态，选择取决于团队使用的工具链
